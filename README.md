# 秘野破关行

`秘野破关行` 是一个纯离线、无外链依赖的 HTML5 Canvas 竖屏像素游戏。  
项目围绕“近战清场 + 大地图探索 + 环境解谜 + 商人交易 + 后期异变装备 + 多幕 Boss 推进”展开，整体气质介于旧掌机游戏、像素闯关游戏和轻剧情互动作品之间。

游戏当前采用统一十幕战役结构：
- 前半段以危险区清场、节奏压迫和近战反打为主
- 中后段逐步加入大地图事件、机关推进、特殊装备和更高压的 Boss 波次
- 第十幕为独立彩蛋关，玩法和前九幕明显不同

---

## 项目特点

- 纯前端离线运行：打开 `index.html` 即可游玩
- 原生 JavaScript + Canvas：没有框架依赖，方便直接改玩法和 UI
- 竖屏掌机感界面：以手机触控和单页离线运行体验为核心
- 战役式推进：不是单关体验，而是连续多幕的成长与收束
- 双层玩法结构：
  - 危险区：贴身近战、清怪、躲伤、Boss 压制
  - 环境区：探索、事件、路线推进、机关解谜
- 后期异变系统：特殊装备会显著改变战斗节奏
- GM 调试菜单：支持跳关、补资源、清场、秒 Boss、直接测试特殊装备

## 核心玩法

### 1. 近战清场

玩家以近战武器为核心推进战斗，不同武器会影响：
- 攻击范围
- 攻击前摇和攻速
- 暴击率与暴击倍率
- 击退和清场手感

战斗幕更强调：
- 贴身输出
- 控制受击次数
- 借冲刺和站位打断敌人
- 在 Boss 压迫下维持输出节奏

### 2. 大地图探索

除战斗外，项目并不是纯清怪游戏。  
玩家需要在地图中寻找：
- 商人
- 补给点
- 事件点
- 机关
- 解谜目标
- 奖励掉落

这部分决定了游戏不只是“打一波怪”，而是带有推进感和路线感的连续冒险。

### 3. 环境解谜

后续幕中会加入：
- 折镜类机关
- 总闸 / 终端类机关
- 线索收集
- 目标完成度评级

环境区和危险区共同组成一条统一战役，而不是完全割裂的两个模式。

### 4. 特殊装备

当前版本重点强化了两种后期异变装备：

- `爆裂追踪（bombgear）`
  - 拾取后自动生效
  - 持续 9 秒
  - 自动发射追踪爆炸弹
  - 爆炸会造成范围伤害、击退和燃烧
  - 第 6 幕后可无视墙体追踪

- `近身焚击（embergear）`
  - 拾取后自动生效
  - 持续 6 秒
  - 敌人靠近会自动被点燃并击退
  - 会造成目标当前生命值百分比伤害
  - 更偏贴身保命和快速清场

### 5. 多幕 Boss 推进

战役后期不再是单 Boss 静态测试，而是会逐步进入：
- 更高血量
- 更高追击压迫
- 多个 Boss 波次
- 不同 Boss 形象和标题
- 更强的后期场面感

## 十幕战役概览

- 第 1–9 幕：正常战役推进
  - 包含危险区、环境区、Boss 区和结算
  - 会逐步加入更强敌人、更复杂事件和更高掉落价值
- 第 10 幕：彩蛋关
  - 采用独立玩法结构
  - 以麦田、旧掌机、双人偏好冲突和脑筋急转弯为核心意象
  - 包含独立互动流程、小游戏和结尾演出

## 操作方式

### 触屏

- 左侧虚拟摇杆：移动
- 右侧按钮：攻击 / 冲刺 / 互动
- 点击 UI：购买、使用道具、切换菜单

### 键盘

- `WASD` / 方向键：移动
- `Z` / `Enter`：互动
- `X`：攻击
- `C` / `Shift`：冲刺
- `Esc`：暂停 / 返回
- `M`：展开地图
- `B`：打开背包
- `Home`：显示 / 隐藏 GM 菜单

## 本地运行

### 方式一：直接打开

直接用浏览器打开根目录下的 `index.html` 即可。

### 方式二：本地静态服务器

如果想避免部分浏览器的本地文件限制，可以在项目目录启动静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```
